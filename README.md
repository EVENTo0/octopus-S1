# Octopus S1 | أخطبوط S1

مشروع لعبة موبايل مستقل ضمن EVENTO، للاستكشاف الصحراوي والإنقاذ بمساعدة رفيق روبوت على هيئة أخطبوط.

**الحالة الحالية:** نموذج Unity 6.3 LTS به مشهد blockout. توثق المراجعة المحلية نجاح فحص C# المرجعي، مع تعطل اختبارات المحرك لغياب الترخيص. محاولة Cloud #1 فشلت عند SCM checkout؛ المحاولة اليدوية #2 قيد المتابعة. لا يوجد APK مثبت على جهاز أو قبول G2/G3. اسم Octopus S1 اسم عمل مؤقت إلى حين التحقق من الاسم والعلامة التجارية.

المشروع مستقل عن SAEED ROYALE وعن العمل القائم في Claude. لا تُنقل شيفرة أو مشاهد أو خرائط أو أصول من تلك المشاريع. وصل المرجع البصري 9045.png وفُتح في 26 أكتوبر 2026. تستخدم اللوحة لفهم الاتجاه البصري وتوزيع الكتالوج؛ تفاصيل المرجع وسقف الإنفاق في وثيقة المرحلة الجديدة.

## التوجه

- لاعب منفرد يستكشف عالمًا صحراويًا خياليًا.
- رفيق روبوت أخطبوط يساعد على الكشف وجمع الإمدادات وإعادة تشغيل الإرسال.
- الحلقة الأولى: استكشاف → موارد → تفعيل محطة → إخلاء.
- العربية والإنجليزية، مع تصميم RTL/LTR للهاتف.
- لا لعب شبكي أو مشتريات داخل اللعبة في الشريحة الأولى.

## بوابات EVENTO

`Discover → Define → Design → Build → Verify → Release → Evolve`

1. G0: تعريف واستقلال المشروع.
2. G1: تصميم اللعبة والكتالوج والشاشات وسجل الأصول.
3. G2: شريحة Unity قابلة للعب.
4. G3: APK مثبت ومجرب على Android فعلي.
5. G4: الموقع التعريفي وكتالوج التطوير.
6. G5: جاهزية الإصدار والتراخيص والخصوصية والأداء.

لا يثبت المفهوم البصري أو نجاح البناء وحده أن اللعبة جاهزة للعب.

## بيئة البناء

يوجد Codespace قائم للمستودع بمواصفات 2-core و8GB RAM و32GB. لا يظهر Unity Editor أو Android `adb` في PATH حتى الآن. استخدام Codespace لتحرير الملفات لا يساوي إمكانية بناء APK؛ يلزم فحص/توفير Unity Editor وAndroid Build Support وSDK/NDK/JDK وترخيص مناسب، ثم التحقق على جهاز فعلي. اعتمد المالك سقفًا إجماليًا قدره 20 USD لهذه المرحلة. أُنشئ هدف Android في Unity Build Automation. قبل المحاولة الثانية عرضت الحصة Windows 1/200 دقيقة وتقرير آخر 7 أيام 0.00 USD (تقديري وقد يتأخر). التشغيل يدوي فقط؛ لا إيجار أو اشتراك جديد. راجع الوثيقة 07 للنتيجة الحالية والتنظيف.
