# Octopus S1 | أخطبوط S1

مشروع لعبة موبايل مستقل ضمن EVENTO، للاستكشاف الصحراوي والإنقاذ بمساعدة رفيق روبوت على هيئة أخطبوط.

**الحالة الحالية:** تأسيس وتصميم. لا يوجد حتى الآن مشروع Unity أو بناء APK مثبت على جهاز. اسم Octopus S1 اسم عمل مؤقت إلى حين التحقق من الاسم والعلامة التجارية.

المشروع مستقل عن SAEED ROYALE وعن العمل القائم في Claude. لا تُنقل شيفرة أو مشاهد أو خرائط أو أصول من تلك المشاريع. لوحة SAEED ROYALE الظاهرة في محادثة التخطيط كانت مرجعًا عامًا لتقسيم الكتالوج فقط؛ ملفها المرفوع غير متاح كملف داخل بيئة العمل.

![Octopus S1 concept board](artwork/concept/octopus-s1-concept-board.jpg)\n\n*لوحة مفهوم أولية؛ ليست لقطة من Unity أو دليل لعب.*\n\n## التوجه\n
- لاعب منفرد يستكشف عالمًا صحراويًا خياليًا.
- رفيق روبوت أخطبوط يساعد على الكشف وجمع الإمدادات وإعادة تشغيل الإرسال.
- الحلقة الأولى: استكشاف → موارد → تفعيل محطة → إخلاء.
- العربية والإنجليزية، مع تصميم RTL/LTR للهاتف.
- لا لعب شبكي أو مشتريات داخل اللعبة في الشريحة الأولى.

## بوابات EVENTO

`Discover → Define → Design → Build → Verify → Release → Evolve`

1. G0: تعريف واستقلال المشروع.
2. G1: تصميم اللعبة والكتالوج والشاشات وسجل الأصول.
3. G2: شريحة Unity قابلة للعب.
4. G3: APK مثبت ومجرب على Android فعلي.
5. G4: الموقع التعريفي وكتالوج التطوير.
6. G5: جاهزية الإصدار والتراخيص والخصوصية والأداء.

لا يثبت المفهوم البصري أو نجاح البناء وحده أن اللعبة جاهزة للعب.

## بيئة البناء

يوجد Codespace قائم للمستودع بمواصفات 2-core و8GB RAM و32GB. لا يظهر Unity Editor أو Android `adb` في PATH حتى الآن. استخدام Codespace لتحرير الملفات لا يساوي إمكانية بناء APK؛ يلزم فحص/توفير Unity Editor وAndroid Build Support وSDK/NDK/JDK وترخيص مناسب، ثم التحقق على جهاز فعلي. لا تُشترى أو تُستأجر موارد دون تحديد حد الميزانية والموافقة على التكلفة.
