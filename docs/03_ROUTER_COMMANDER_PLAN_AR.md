# خطة EVENTO Router Commander — Octopus S1

## أمر التوجيه

**المسار:** منتج لعبة موبايل مستقل + موقع تعريفي وكتالوج  
**الهدف:** شريحة لعب Android قابلة للتثبيت والتجربة، ثم توسعة محسوبة.  
**المالك:** EVENTO.  
**المصدر الوحيد للحقيقة:** هذا المستودع، وسجل الأصول، وأدلة البناء المرتبطة بالالتزام.  
**قواعد:** Finish > Start؛ Reuse Before Rebuild؛ Evidence Before Claim؛ Security and License Before Sale؛ لا نشر تلقائي.

## ضوابط النطاق

- MVP = لاعب منفرد، حوض واحد، روبوت واحد، مهمة إنقاذ/إرسال، موارد بسيطة، إخلاء.
- لا تُبنى شبكة أو متجر أو اقتصاد أو حسابات قبل اختبار الحلقة الأساسية.
- يجب تشغيل الوظيفة نفسها في العالم الفعلي للمحرك؛ نجاح السكربتات أو lint لا يثبت أن اللعبة قابلة للعب.
- لكل تغيير مستودعي فحص قابل للتكرار؛ لا دمج تلقائي.
- يطابق الموقع الحالة في المستودع؛ لا يدعي أن Assets Planned أو Blockout أصول مكتملة.

## Codespace مقابل Unity/Android

Codespace الحالي جهاز تطوير سحابي 2-core / 8GB RAM / 32GB. فحص الواجهة أظهر أن Unity Editor وADB غير متاحين عبر PATH في البيئة العامة؛ لم نفحص بعد وجود محرك مخفي في مجلد آخر أو بيئة SDK كاملة. لا نعتبر Codespace وحده مثبتًا لقدرته على إنشاء APK. نتحقق من المسارات والإصدارات والتخزين والأداء، ثم نختار:

1. Unity Build Support في Codespace إذا أمكن ترخيصه وتركيبه بصورة مدعومة وكان زمن البناء/الذاكرة مقبولًا.
2. جهاز مستأجر أو مستضاف عند الحاجة إلى واجهة Unity وتجربة فعلية. قبل الحجز نحدد مواصفات الحد الأدنى والميزانية وفترة الاستخدام.
3. عامل CI مؤقت من مزود مناسب فقط بعد احتساب تكلفة الدقائق والتراخيص وحماية أسرار Unity.

لا ترفع ملف الترخيص أو مفاتيح النشر إلى Git. تحفظ الأسرار في مخزن مناسب وتستخدم بأقل صلاحية ومدة.
