# استكمال Octopus S1 على حاسب Windows

## حدود الاتصال
فتح ChatGPT أو Claude Code على Windows لا يربط الحاسب بهذه الجلسة السحابية.
فُحصت أدوات الجلسة وإعداد البيئة: لا تحكم بسطح المكتب، ولا هوية جهاز،
ولا VPN أو وجهة TCP مهيأة. لم يُجر اتصال بحاسب المالك.
المسار المتاح الآن هو تشغيل Codex أو Claude Code محليًا داخل المستودع،
واستخدام GitHub لتبادل التغييرات والسجلات المنقحة. لا يحتاج هذا المسار SSH
أو فتح منافذ أو إرسال كلمات مرور أو ملفات ترخيص للدردشة.

## بدء الوكيل المحلي
إذا لم يكن المشروع موجودًا، افتح Terminal على Windows ونفّذ:
```powershell
git clone --branch codex/octopus-s1-charter-and-prototype https://github.com/EVENTo0/octopus-S1.git
cd octopus-S1
```
إذا كان موجودًا، افتحه في الوكيل المحلي واطلب فحص git status ثم جلب تحديثات
الفرع دون الكتابة فوق تغييرات محلية. لا تنسخ المستودع فوق مشروع آخر.
افتح Codex المحلي أو Claude Code داخل المجلد والصق تعليمات التسليم أدناه.

## تعليمات جاهزة للوكيل المحلي
> استكمل Octopus S1 من المستودع EVENTo0/octopus-S1، فرع
> codex/octopus-s1-charter-and-prototype وDraft PR #1. اقرأ تعليمات المستودع
> والوثائق 04 إلى 08 أولًا. حافظ على أي عمل محلي موجود؛ لا تستخدم reset --hard.
> اللعبة مستقلة عن SAEED ROYALE ومشروع Claude السابق؛ لا تنقل منهما أصولًا أو شيفرات.
>
> لديك تفويض لفحص هذا الحاسب Windows واستخدام موارده لبناء المشروع وإصلاح
> أخطاء الاستيراد والترجمة والتشغيل. الحد المالي الإجمالي للمرحلة 20 USD،
> وليس لكل محاولة؛ ابدأ بالموارد المحلية ولا تنشئ اشتراكًا أو إيجارًا تلقائيًا.
> لا تفترض الرصيد المتبقي من تاريخ الوثائق؛ لم تُقرأ فاتورة الحساب.
>
> افحص وجود Unity 6000.3.25f1 وAndroid Build Support مع SDK/NDK/OpenJDK
> المطابقة والترخيص. استخدم سكربت scripts/unity-local.ps1 مع doctor ثم test
> ثم build. يمكن تمرير -UnityEditor بمسار Unity.exe إذا كان التثبيت مخصصًا.
> عند غياب المحرر استخدم تثبيت Unity Hub الرسمي؛ إذا تطلب التفعيل دخول
> حساب أو قبول شروط، اطلب من المالك إتمامه داخل Hub نفسه، ولا تطلب أسراره.
> لا تغير إصدار Unity أو تثبت تراخيص غير صالحة.
>
> راجع حالة المحاولة السحابية #2 في الوثيقة 07 قبل بدء أي محاولة مدفوعة أخرى؛
> حالة Queue المسجلة ليست نتيجة نهائية. لا تعدل اعتماد Cloud من أجل المسار المحلي.
> لم يسجل استيراد ناجح للمشروع عند إعداد هذا التسليم، لذلك قد تتولد ملفات
> ProjectSettings وPackages/packages-lock.json وملفات .meta في أول استيراد.
> راجعها وأودع تغييرات المصدر اللازمة قبل البناء. أصلح أخطاء الاستيراد
> والترجمة الفعلية، ثم اختبر PlayMode؛ لا تعتبر فحص Roslyn السابق بديلًا عنه.
> لا تتجاوز فشل الاختبارات ولا ترفع بيانات حساب أو سجلات تحتوي أسرارًا.
>
> مولّد المشهد هو OctopusS1SceneBuilder.BuildPrototypeScene؛ أمر البناء
> OctopusS1Build.Android ينشئ المشهد ويطبق إعدادات Android. لا تعِد تطوير اللعبة.
> احتفظ بأدلة نتائج الاختبارات ومشكلات الحركة والجمع والتفاعل وإكمال المهمة.
> بعد نجاح البناء، سجّل SHA المصدر والإصدار وبصمة APK المولدة في Builds/Android.
> لا تصف التطبيق بأنه مختبر على جهاز قبل إجراء التجربة.
>
> إذا توفر هاتف Android ARM64، اسأل المالك أي جهاز مصرح به ثم استخدم adb
> بعد موافقته على اتصال USB والتثبيت. تحقق من الحركة باللمس وجمع ثلاث خلايا
> مرة واحدة ورفض تفعيل البرج مبكرًا ثم تفعيله وإكمال الإخلاء، وسجل logcat والأداء.
> إن لم يوجد هاتف، أكمل APK ووثّق أن G3 ما زالت غير مقبولة.
>
> احفظ الإصلاحات على فرع العمل وارفعها إلى PR الحالي دون دمج أو نشر.
> لا ترفع APK أو مجلد Unity أو Library إلى Git؛ سلّم APK للمالك محليًا
> مع البصمة وتقرير مختصر بما نُفذ وما بقي. لا تنشئ اتصال تحكم دائمًا بالحاسب.

## أوامر PowerShell
من جذر المستودع:
```powershell
powershell -NoProfile -File .\scripts\unity-local.ps1 -Mode doctor
powershell -NoProfile -File .\scripts\unity-local.ps1 -Mode test
powershell -NoProfile -File .\scripts\unity-local.ps1 -Mode build
```
للتثبيت المخصص أضف مثلًا:
```powershell
-UnityEditor "D:\Unity\6000.3.25f1\Editor\Unity.exe"
```
يمكن استخدام pwsh بدل powershell إن كان مثبتًا.
إذا منعت سياسة تنفيذ السكربتات التشغيل، اعرض الخطأ للوكيل المحلي لمعالجة
السياسة المطبقة على جهازك؛ لا تغير السياسة العامة أو تتجاوز سياسات مؤسسة.

المخرجات: Logs/tests.log وLogs/playmode.xml وLogs/android.log،
وBuilds/Android/OctopusS1-0.1.0.apk و.apk.sha256 و.build.json.
السكربت يحذف نتائج الاختبار وملفات الإخراج القديمة قبل المحاولة المناسبة،
ولا يصدر manifest عند فشل Unity أو غياب APK. يجب تشغيل الاختبارات قبل البناء؛
وضع all يتوقف تلقائيًا إذا فشلت الاختبارات.

## حالة التحقق من هذا التسليم
نجح فحص صياغة السكربت بمحلل PowerShell 7.4.6 على Linux؛ لم يُنفذ
مسار التشغيل على Windows. فحص C# المرجعي وفحوص Python/Bash السابقة لا تثبت
صحة التشغيل على Windows أو ترخيص الحاسب. لم يُربط الحاسب أو يُثبت عليه شيء من هذه الجلسة.
