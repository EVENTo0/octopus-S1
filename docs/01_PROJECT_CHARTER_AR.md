# ميثاق مشروع Octopus S1

**الحالة:** تأسيس المشروع — لم يبدأ بناء Unity أو APK بعد  
**المستودع:** `EVENTo0/octopus-S1`  
**العلاقة:** مشروع EVENTO مستقل عن SAEED ROYALE وعن أي فرع أو مستودع تابع لمشروع سعيد القائم في Claude.

## الفكرة

Octopus S1 لعبة استكشاف وبقاء وإنقاذ للموبايل تدور في عالم صحراوي خيالي. يقود اللاعب مستكشفًا واحدًا، ويرافقه روبوت أخطبوط ذكي يساعده في كشف المسارات، وجمع الموارد، وتشغيل أجهزة الاتصالات. الهدف هو إنقاذ فرق الاستكشاف وإعادة تشغيل شبكة محطات الإرسال.

اسم العمل الحالي **Octopus S1 / أخطبوط S1**. قبل النشر التجاري، يلزم التحقق من توافر الاسم والعلامة التجارية واسم الحزمة.

## ما الذي يجعلها مستقلة

- مستودع وملكية فنية وهوية وشخصيات وقصة وخرائط جديدة.
- لا استيراد لشيفرة أو مشاهد أو ملفات أو شخصيات من SAEED ROYALE أو Projectx.
- لوحة SAEED ROYALE الظاهرة في المحادثة مرجع عام لتقسيم العرض فقط. الملف المرفوع نفسه لم يصل إلى مساحة العمل، ولم يُستخرج منه أصل.
- الاتجاه الجديد يركز على روبوت أخطبوط مرافق وعالم استكشاف وإنقاذ، لا على إعادة بناء لعبة معركة ملكية.
- أي مورد خارجي لاحق يسجل مصدره وترخيصه في سجل الأصول.

## تجربة الإصدار الأول

نموذج أولي أحادي اللاعب يثبت دورة لعب قصيرة قابلة للتجربة:

1. دخول محطة بداية آمنة.
2. التحرك والاستكشاف في منطقة صحراوية واحدة.
3. استخدام الروبوت للكشف عن الموارد أو نقطة الإرسال.
4. جمع الموارد والتفاعل مع جهاز الإرسال.
5. العودة إلى نقطة الإخلاء وإظهار نتيجة المهمة.

الإصدار الأول لا يتطلب لعبًا شبكيًا، متجرًا، حسابات، أو اقتصادًا مدفوعًا. تُحسم هذه الميزات بعد اختبار المتعة والأداء على جهاز Android حقيقي.

## أسس التوجيه — EVENTO Router Commander

نطبق دورة **Discover → Define → Design → Build → Verify → Release → Evolve** على بوابات صغيرة:

- **G0 — استقلال المشروع:** تثبيت النطاق والهوية والمستودع وسجل الموارد.
- **G1 — تصميم قابل للتنفيذ:** خريطة المنطقة، واجهات الهاتف، الشخصية، الروبوت، والأصول المطلوبة.
- **G2 — شريحة لعب:** حركة اللاعب، كاميرا، روبوت مرافق، تفاعل واحد، ومهمة إخلاء واحدة.
- **G3 — قبول Android:** بناء APK وتثبيته وتشغيله على جهاز فعلي؛ إثبات التحكم والأداء والحفظ.
- **G4 — موقع المشروع:** موقع تعريفي وكتالوج بصري ثنائي اللغة مع رابط تنزيل لا يظهر إلا بعد قبول APK.
- **G5 — جاهزية الإصدار:** مراجعة الأداء والخصوصية والتراخيص وسلامة البناء والتوزيع.

كل بوابة تسجل القرار والالتزام والاختبار والدليل. لا تُعلن ميزة جاهزة من تصميم أو ملف توثيق وحده.

## خطة البيئة

الموجود حاليًا: Codespace نشط للمستودع بمواصفات 2 نواة و8GB RAM و32GB تخزين. الفحص الأولي أظهر بيئة عامة فيها Java و.NET، ولا يظهر Unity Editor أو Android `adb` في PATH. لذلك يستخدم Codespace لتحرير المشروع والوثائق والموقع والاختبارات النصية. بناء Unity وAPK يحتاج وجود Unity Editor مع Android Build Support وSDK/NDK/JDK وترخيص مناسب. لم يُنفّذ تثبيت أو بناء بعد.

قبل استئجار جهاز أو ترقية مدفوعة، نتحقق من خيارات البناء الحالية والترخيص والتكلفة. أي حجز أو شراء يحتاج ميزانية وحدًا ماليًا محددًا.
