# كتالوج اللعبة والموقع — Octopus S1

**إصدار التصميم:** 0.1 — مخطط إنتاج، وليس قائمة أصول منجزة  
**اتجاه بصري:** صحراوي سينمائي دافئ؛ رمل ذهبي وصخر طوبي؛ واجهات بلون كحلي/أخضر بترولي مع إشارات سماوية؛ روبوت أخطبوط ودود واضح الصورة.  
**مرجع اللوحة:** صورة تصورية مستقلة أُنتجت لهذه المرحلة في المحادثة. لا تمثل أصلًا داخل Unity.

## 1. وعد اللعبة

استكشف حوضًا صحراويًا واسعًا، اعثر على فرق انقطع اتصالها، واعمل مع رفيقك الروبوت الأخطبوط لإعادة تشغيل محطات الإرسال وإخراج الجميع بأمان. نبرة المغامرة هادئة ومشوقة وتناسب جلسات الهاتف القصيرة.

## 2. فهرس صفحات الكتالوج البصري

1. الغلاف والهوية — الاسم المؤقت وشعار الأخطبوط واتجاه الألوان.
2. ملخص التجربة — حلقة اللعب، الجمهور، المنصة، ومدة المهمة.
3. عالم اللعبة — خريطة أولية بعلامات المناطق ومسارات الحركة.
4. محطة الإخلاء — مركز العودة وتبديل الأدوات ونتيجة المهمة.
5. قرية الواحة — منطقة آمنة، إمدادات، وشخصيات مساعدة.
6. وادي المرايا — مسارات صخرية وانعكاسات ضوئية للكشف.
7. برج الإرسال — هدف المهمة والتفاعل الأساسي.
8. حقل العواصف — مجال لاحق يتطلب إشارة رؤية وصوت خاصة.
9. موقع الحطام — مورد ومهمة إنقاذ جانبية.
10. الشخصية الرئيسية — ملابس وأحجام ومراحل حركة دون استنساخ شخصية مرجعية.
11. رفيق الأخطبوط — الشكل الأساسي، الإيماءات، إضاءة الحالة، وقدراته.
12. شخصيات القصة — فريق الإنقاذ وشخصيات الواحة؛ الظهور مؤجل بعد الشريحة الأولى.
13. التحكم باللمس — عصا الحركة، تحريك الرؤية، تفاعل، قدرة الرفيق، إيقاف.
14. شاشة اللعب — مؤشر المهمة، الصحة/الطاقة عند الحاجة، الخريطة المصغرة، زر التفاعل.
15. خريطة المهمة — اللاعب، الإرسال، الإخلاء، الموارد، ومناطق الخطر.
16. قائمة المهمة — الهدف، التقدم، المكافآت، وزر المتابعة.
17. الحقيبة — الموارد، الأدوات، السعة، وأسعارها إن أضيف اقتصاد لاحقًا.
18. شاشة الروبوت — حالة الطاقة، الكشف، العودة، وتحسينات مستقبلية.
19. شاشة النتيجة — من تم إنقاذه، الموارد، الزمن، وتقييم واضح.
20. شاشة البداية — متابعة، إعدادات، دليل سريع، الخصوصية.
21. إعدادات الهاتف — الصوت، جودة الرسوم، الحساسية، اللغة، وحفظ البيانات.
22. صفحة التقدم — المهام المكتملة والإنجازات؛ خارج الشريحة الأولى.
23. حالات الفشل — نفاد الطاقة، خروج عن الحدود، انقطاع اللعب، ومحاولة جديدة.
24. صفحة الموقع الرئيسية — تعريف موجز، لقطة فعلية من البناء، دعوة للاطلاع.
25. صفحة عالم اللعبة — خريطة ومناطق عليها وسم تصميم/قيد التنفيذ/منجزة.
26. صفحة الشخصيات والرفيق — بطاقات الشخصيات مع حالة اعتماد التصميم.
27. صفحة أسلوب اللعب — فيديو/صور موثقة من تشغيل اللعبة فقط.
28. صفحة الكتالوج والأصول — أصول معتمدة، مصادرها، ترخيصها وحالتها.
29. صفحة مراحل التطوير — بوابات EVENTO والأدلة المقبولة.
30. صفحة التحميل — تُفعّل عند قبول APK وتوضح الإصدار والجهاز والدليل.
31. صفحة الخصوصية والدعم — جمع البيانات ووسيلة الدعم.
32. صفحة فريق التطوير — EVENTO وبيانات المشروع دون ادعاء شراكات.

لا تعرض صفحات أو صور العمل قيد التنفيذ على أنها ميزات لعب فعلية. تحمل النماذج التصورية شارة **Concept / تصور** حتى وجود لقطة من المحرك.

## 3. وحدات اللعبة

| الوحدة | دورها | حد الشريحة الأولى |
|---|---|---|
| الاستكشاف | الحركة والتوجيه واكتشاف النقاط | منطقة واحدة |
| رفيق Octopus | كشف موارد/إشارة، مرافقة اللاعب، العودة | قدرة كشف واحدة |
| المهام | تعليم الهدف وحفظ التقدم | مهمة رئيسية واحدة |
| التفاعل | تشغيل برج واستلام العناصر | نوع تفاعل واحد قابل لإعادة الاستخدام |
| الموارد | مورد مهمة محدود وواضح | ثلاثة عناصر من نوع واحد |
| الإخلاء | إغلاق الحلقة وإظهار النتيجة | نقطة واحدة |
| القائمة والإعدادات | بدء وإيقاف وضبط اللغة والصوت | عربي/إنجليزي وهيكل أولي |
| اللعب الجماعي | تعاون إنقاذ | مؤجل إلى ما بعد إثبات المتعة والأداء |

## 4. سجل الأصول المطلوب

كل عنصر يمر بحالات: **Planned → Blockout → Draft → Review → Approved → Integrated → Verified**. تضاف حقول المصدر والترخيص والنسخة والبصمة وطريقة التحقق.

| الحزمة | أصول البداية | بوابة القبول |
|---|---|---|
| الشخصية | نموذج/هيكل، خامات، Idle/Walk/Run | استيراد Unity، نسب صحيحة، حركة واضحة |
| الروبوت | نموذج أخطبوط، عيون/إضاءة، 4 إيماءات، صوتيات واجهة | قراءة حالته في شاشة الهاتف وعدم حجب اللاعب |
| البيئة | أرضية، كتل صخرية، واحة، محطة إرسال، إخلاء | مشهد قابل للمشي وميزانية أداء محمول |
| الواجهة | أيقونات وخط عربي/لاتيني وخرائط مصغرة | اختبار وضوح عربي/إنجليزي على نسبة هاتف |
| المؤثرات | رياح، ماء، كشف، تفعيل وإخلاء | مستوى صوت متوازن وحجم ملفات محدود |
| الموقع | غلاف، خريطة، بطاقات، معرض، صفحات الحالة | الاستجابة للهاتف ووسوم التصور/الحقيقة |
| التسليم | APK، رقم إصدار، سجل فحص، تعليمات تثبيت | تثبيت وتشغيل على جهاز Android حقيقي |

لا نضيف أصول متجر قبل تأكيد قابلية التوزيع التجاري وحق الاستخدام. استخدام نماذج أولية بدائية مسموح لإثبات اللعب ويجب وسمها **Placeholder**.

## 5. هيكل الموقع

- **الرئيسية:** تعريف ووعد اللعبة، لوحة الاتجاه البصري، آخر بوابة مثبتة.
- **اللعبة:** الفكرة، الحلقة، دليل التحكم، المناطق.
- **الكتالوج:** الشخصيات، الرفيق، المناطق، الواجهات، الأصول.
- **التطوير:** سجل البوابات والدليل المنشور بإذن.
- **التحميل:** لا يظهر إلا بعد G3؛ الإصدار والبصمة والملاحظات والأجهزة المختبرة.
- **عن المشروع:** EVENTO، الاستقلال، التراخيص، الخصوصية.
- دعم العربية RTL والإنجليزية LTR، مع مسارات واضحة للوحة المفاتيح وقارئ الشاشة.

## 6. سياسة الصور والدليل

- لوحة المفهوم والصور التوليدية: اتجاه فني فقط؛ لا تُستخدم بدل لقطة Unity أو إثبات أداء.
- صور الكتالوج الفعلية: تسجل الملف والالتزام ومصدر الأصل والحالة.
- الموقع لا يعرض زر تنزيل APK قبل تسجيل قبول G3.
- أي فيديو يذكر نوع الجهاز وإصدار البناء وتاريخ الالتقاط، أو يوسم بوضوح بأنه تصور.
